# medical-portfolio

Personal medical portfolio website of **Dr. Gazi Sazzad Hossain** — built with plain HTML, CSS and a little vanilla JavaScript.

## Structure

```
index.html      → single-page site
css/style.css   → all styles
js/main.js      → small interactions
images/         → photos and section images
```

## Updating content

| What | Where |
|---|---|
| Profile photo | replace `images/profile.jpg` (portrait, about 3:4) |
| Work card photos | replace `images/work-*.jpg` |
| Featured Highlights photos | in `index.html`, swap each `.media-ph` placeholder's inner icons for `<img src="images/..." alt="...">` |
| Email | search `contact@example.com` in `index.html` |
| Social links | the `.socials` list in `index.html` — replace each `href="#"` |

## Run locally

Open `index.html` in any browser — no build step needed.
